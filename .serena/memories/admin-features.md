Admin features: User management (list/search/status/delete), recipe moderation (approve/reject/pending queue), dashboard statistics, and activity log audit trail. Backend API: GET/POST /api/admin/users, POST /api/admin/update-user-status, DELETE /api/admin/users/:id, GET /api/admin/pending-recipes, POST /api/admin/approve-recipe, GET /api/admin/activity-log. Frontend: AdminStats.jsx displays stats & recent activity, AdminRecipes.jsx manages approval queue, UserList.jsx handles user status updates. All admin actions logged to activity_log table. Uses stored procedures: usp_ApproveRecipe, usp_DeleteRecipe, usp_GetRecipeStat.
